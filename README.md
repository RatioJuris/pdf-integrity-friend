# PDF Integrity Friend

**Version:** 1.0-Beta  
**Publisher:** Ratio Juris  
**Repository:** [@RatioJuris/pdf-integrity-friend](https://github.com/RatioJuris/pdf-integrity-friend/)

---

## Overview

PDF Integrity Friend is a Windows desktop application for secure PDF signing, visible signature placement, document integrity verification, timestamping, and PDF permission management.

---

## Features

### PDF Viewer
- Open PDF documents
- Large document support
- Page thumbnails
- Multi-page browsing
- High DPI support

### Visible Signatures
- Multiple signatures per page
- Multiple pages supported
- Signature resize support
- Signature preview

### Timestamping
Planned RFC3161 support:
- DigiCert TSA
- Sectigo TSA
- GlobalSign TSA
- Entrust TSA
- Custom TSA endpoints

### Security Controls
- Disable Editing
- Disable Printing
- Disable Copy
- Disable Commenting

All security options are disabled by default.

### Themes
- Light Theme
- Dark Theme
